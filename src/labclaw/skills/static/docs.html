Getting Started

Get up and running with the Cloud Brain API in three steps. Access 2,400+ scientific tools through a single unified interface.

Base URL: https://brain.labclaw.org

1
Get your API key
Request an API key from the LabClaw team. You will receive an X-API-Key token for authentication.
2
Explore available tools
Call GET /brain/tools to list all available scientific tools, or browse them in the Tool Explorer.
3
Execute a tool
Send a POST /brain/execute request with the tool name and arguments. Try it live in the Playground.

Authentication

All API requests must include your API key in the X-API-Key header. Requests without a valid key will receive a 401 Unauthorized response.

# Include the API key in every request
curl -H "X-API-Key: your-api-key-here" \
  https://brain.labclaw.org/brain/tools

Keep your API key secure. Do not expose it in client-side code or public repositories. If your key is compromised, contact the team for a rotation.

API Endpoints

The Cloud Brain API exposes five endpoints for tool discovery, health monitoring, and execution.

GET /brain/health

Check the health status of all registered skills. Returns a JSON object mapping each skill name to its availability (boolean).

Response

// 200 OK
{
  "tool_universe": true,
  "sci_write": true,
  "biomni": false
}
GET /brain/tools

List all available tools across all registered skills. Each tool includes its name and description.

Response

// 200 OK
[
  {
    "name": "UniProt_get_function_by_accession",
    "description": "Get protein function annotation from UniProt"
  },
  {
    "name": "ChEMBL_search_molecules",
    "description": "Search for molecules in ChEMBL database"
  }
]
GET /brain/skills

List all registered skills with their metadata, including the number of tools each skill provides.

Response

// 200 OK
[
  {
    "name": "tool_universe",
    "tool_count": 2400,
    "healthy": true
  }
]
GET /brain/inventory

Get a full inventory of tools organized by skill, including categories and tool counts. Useful for building tool browsers.

Response

// 200 OK
{
  "skills": [
    {
      "name": "tool_universe",
      "tools": ["UniProt_get_function_by_accession", "..."],
      "categories": ["Protein & Genomics", "Drug Discovery"]
    }
  ],
  "total_tools": 2400
}
POST /brain/execute

Execute a specific tool with the given arguments. This is the primary endpoint for running scientific queries.

Request Body

FieldTypeRequiredDescription
tool_namestringYesName of the tool to execute
argumentsobjectYesTool-specific arguments as key-value pairs

Request Example

{
  "tool_name": "UniProt_get_function_by_accession",
  "arguments": {
    "accession": "P38398"
  }
}

Response

// 200 OK
{
  "result": {
    "accession": "P38398",
    "function": "E3 ubiquitin-protein ligase that..."
  },
  "tool_name": "UniProt_get_function_by_accession",
  "duration_ms": 342
}

Code Examples

Ready-to-use examples for integrating Cloud Brain into your applications.

import requests

BASE_URL = "https://brain.labclaw.org"
HEADERS = {
    "X-API-Key": "your-api-key-here",
    "Content-Type": "application/json",
}

# List all tools
tools = requests.get(f"{BASE_URL}/brain/tools", headers=HEADERS).json()
print(f"Available tools: {len(tools)}")

# Execute a tool
response = requests.post(
    f"{BASE_URL}/brain/execute",
    headers=HEADERS,
    json={
        "tool_name": "UniProt_get_function_by_accession",
        "arguments": {"accession": "P38398"},
    },
)
result = response.json()
print(result)
const BASE_URL = "https://brain.labclaw.org";
const API_KEY = "your-api-key-here";

const headers = {
  "X-API-Key": API_KEY,
  "Content-Type": "application/json",
};

// List all tools
const tools = await fetch(`${BASE_URL}/brain/tools`, { headers })
  .then(r => r.json());
console.log(`Available tools: ${tools.length}`);

// Execute a tool
const result = await fetch(`${BASE_URL}/brain/execute`, {
  method: "POST",
  headers,
  body: JSON.stringify({
    tool_name: "UniProt_get_function_by_accession",
    arguments: { accession: "P38398" },
  }),
}).then(r => r.json());

console.log(result);

  -H "X-API-Key: your-api-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "tool_name": "UniProt_get_function_by_accession",
    "arguments": {"accession": "P38398"}
  }' \
  https://brain.labclaw.org/brain/execute | jq .

Rate Limits

API rate limits are applied per API key. Exceeding the limit returns 429 Too Many Requests.

TierRequests / MinuteRequests / DayMax Concurrent
Free301,0005
Standard12010,00020
Enterprise600100,000100

Rate limit headers are included in every response:

HeaderDescription
X-RateLimit-LimitMaximum requests per minute for your tier
X-RateLimit-RemainingRequests remaining in current window
X-RateLimit-ResetUnix timestamp when the window resets
